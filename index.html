How to use it

Set the starting point

Type your own initial weights and pick or paste a dataset (CSV). Click the plot to add points.

Step the loop

Step one epoch, ten, or press Play. Turn on Phase by phase to run forward → loss → gradients → update one press at a time.

Read the numbers

The trajectory chart shows every parameter across epochs. Click any epoch to open its full worked arithmetic.

Break it on purpose

Crank the learning rate until training diverges, or feed XOR to logistic regression, and see exactly why.
